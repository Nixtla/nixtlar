# Get NIXTLA_API_KEY from options or from .Renviron This is a private function of 'nixtlar'

Get NIXTLA_API_KEY from options or from .Renviron This is a private
function of 'nixtlar'

## Usage

``` r
.get_client_steup()
```

## Value

If available, the NIXTLA_API_KEY. Otherwise it returns an error and a
message asking the user to set the 'API' key.

## Examples

``` r
if (FALSE) { # \dontrun{
  .get_api_key()
} # }
```
