# Get the 'nixtlar' client version string This is a private function of 'nixtlar'

Get the 'nixtlar' client version string This is a private function of
'nixtlar'

## Usage

``` r
.get_client_version()
```

## Value

A character string of the form `"R-x.y.z"`, where `x.y.z` is the
installed 'nixtlar' package version (read from the DESCRIPTION file).

## Examples

``` r
if (FALSE) { # \dontrun{
  .get_client_version()
} # }
```
