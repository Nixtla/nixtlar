# Set 'API' key in global environment

This function will be deprecated in future versions. Please use
`nixtla_client_setup` instead.

## Usage

``` r
nixtla_set_api_key(api_key)
```

## Arguments

- api_key:

  The user's 'API' key. Get yours here: https://nixtla.io/dashboard/

## Value

A message indicating the 'API' key has been set in the global
environment.

## Examples

``` r
if (FALSE) { # \dontrun{
  nixtlar::nixtla_set_api_key("Your API key")
} # }
```
